# Phase 06.1 Plan 05: Publish-boundary wiring for per-bonus RP and history-row percentiles Summary

**`TeamSeasonMatchSchema` gains predicted/actual per-bonus RP fields with a three-state absent/null/array contract, `publish.ts` gains `actualBonusFlagsForSeason` (once per season, algorithm-independent) and `withHistoryPercentiles` (once per algorithm-season, season-final ranking) — verified against the real 2022 corpus with a 3,062-team, zero-mismatch invariant.**

## Accomplishments

- `TeamSeasonMatchSchema` widened with `redBonusRp`/`blueBonusRp` (optional arrays of `[0,1]` predicted per-bonus probabilities, positional per PD-04) and `actualRedBonusRp`/`actualBlueBonusRp` (optional, nullable arrays of booleans, mirroring `actualRedRp`'s null contract exactly) — plus three new refines (non-empty when present, equal predicted lengths, equal non-null actual lengths). Every existing artifact still parses; `browserSafeSchemas.test.ts` confirms no new import reached the browser bundle.
- `actualBonusFlagsForSeason(stream, season)` computes the algorithm-independent actual per-bonus outcome for a whole season's matches in one pass, using the exact same eligibility/parse-failure predicates `sigma1/index.ts`'s `update()` already uses to decide whether to fold a match's RP observation — proven, not assumed, by two real-shaped raw score-breakdown fixtures (2022, 2024) cross-checked against each season's own rule module's `parse()` output.
- Predicted per-bonus marginals are rounded exactly once, at `ROUNDING_RULE.probability`, never routed through `roundPmf`'s residual-redistribution path (that path is only meaningful for a distribution that must sum to 1; these are independent marginals). Actual per-bonus flags are threaded through a `ReadonlyMap` parameter and conditionally spread only inside a played match's row — an unplayed match, and an artifact built with no map entry for a given match key, both carry neither key.
- `withHistoryPercentiles` attaches a season-final percentile to every allowlisted `metricHistory` row metric, ranked against a pool (`sortedPoolsByMetric`) built exactly once per `(algorithm, season)` — never per team, never per row — from the same team-pool membership list the season-final percentile pass (`withPercentiles`) already uses, so the two rankings can never disagree about who is in the field.
- The percentile invariant was proven against the real corpus, not just synthetic fixtures: replaying the full non-offseason 2022 season (14,677 matches) with `epa` (chosen for its per-team-independent state — no cross-team least-squares coupling to introduce drift between "last match snapshot" and "season-final value"), every one of 3,062 teams satisfied the value-equality precondition and every one produced an exact percentile match — a floor of 50 was required, 3,062 were measured.
