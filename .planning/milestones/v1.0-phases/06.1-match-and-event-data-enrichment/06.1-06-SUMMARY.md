# Phase 06.1 Plan 06: Wire per-bonus RP dots and per-event rarity tiers into the team page Summary

**`BonusRpDots` and `MatchTable` now render real predicted/actual bonus states from plan 06.1-05's published arrays, and `EventSection`'s per-event metric line carries rarity tiers from each history row's own percentile plus a visible "vs season-final field" basis caption.**

## Performance

- **Duration:** ~40 min
- **Tasks:** 3
- **Files modified:** 7

## Accomplishments

- `apps/web/src/lib/bonusRp.ts` gained `PREDICTED_BONUS_THRESHOLD` (0.5), `bonusStatesFromProbabilities`, `bonusStatesFromFlags`, and `bonusDotLabel` — pure functions mapping the three published per-bonus states (a probability, a boolean, absence) to exactly one `BonusRpState`, with the exact-0.5-is-earned boundary and the null-is-not-missed rule each pinned by dedicated adjacent test cases (29 total tests in `bonusRp.test.ts`).
- `BonusRpDots` widened with an optional `probabilities` prop, routed through `bonusDotLabel` for both `title` and `aria-label`, so a predicted dot's tooltip now carries the real percentage (e.g. "predicted 72% likely") without changing any element structure, class name, or testid.
- `MatchTable.tsx`'s `PredictedScoreLine`/`ActualScoreLine` now read each alliance's own `redBonusRp`/`blueBonusRp`/`actualRedBonusRp`/`actualBlueBonusRp` off the match row and compute real dot states via `bonusStatesFromProbabilities`/`bonusStatesFromFlags`, with the dot count derived from `bonusRpForSeason(season).length` so the state array and the rendered dot array can never disagree about length. Verified for both a two-bonus (2024) and a three-bonus (2025) season, with a dedicated cross-alliance-read test.
- `EventSection.tsx`'s per-event metric tiles now pass `tierForPercentile(tile.metric.percentile)` — sourced from the history row's own published percentile, never the team's season-final metric record (the exact F-06-3 substitution). A new basis caption (`event-tier-basis-{eventKey}`) renders as the last child of the metric line only when at least one rendered tile carries a percentile, with short visible text ("vs season-final field") and the full sentence in its `title` attribute.
- No change to `apps/web/src/lib/tiers.ts` or `apps/web/src/styles/theme.css` (verified via empty diffs) — every visual element reuses existing tokens and classes.
