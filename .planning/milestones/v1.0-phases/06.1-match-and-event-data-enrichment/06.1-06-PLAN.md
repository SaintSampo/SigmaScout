<planner_decisions>
- **PD-11 — The predicted-dot threshold is a published probability of 0.5 or greater, and the exact
  boundary renders as earned.** `BonusRpState` has three members and none of them is a probability,
  so a threshold is unavoidable the moment a probability drives a two-state mark. Half-up matches
  the codebase's existing half-away-from-zero rounding convention and matches `sigma1/index.ts`'s own
  tie handling, where a win probability of exactly 0.5 resolves to red. The constant is named and
  exported so the number is greppable rather than inline. **Reversibility: reversible.**
- **PD-12 — The dot's tooltip and accessible label carry the predicted percentage.** A two-state mark
  cannot express a 51% prediction, and this project's stated core value is honest uncertainty. The
  visual is unchanged; only the label text gains the number. This stays inside D-06.1-B's condition
  because it adds no rendered element — it changes an attribute on an element that already exists
  and already takes the props. **Reversibility: reversible.**
- **PD-13 — Elimination-match dots stay in the unknown state, and that is recorded rather than
  fixed here.** Bonus ranking points are not awarded outside qualification matches, so the honest
  state for an elimination row is "not applicable" — which the three-member state vocabulary has no
  word for. Rendering unknown is the closest non-false option and is exactly today's behaviour, so
  this plan changes nothing for those rows. Success criterion 1 scopes itself to played
  qualification matches, so this is inside the phase's stated target. Recorded as a follow-up
  candidate for a future phase, not planned here, and explicitly not "fixed" by rendering the dots
  hollow. **Reversibility: reversible.**
- **PD-14 — The basis caption is visible text, not a hover title alone.** A title attribute is
  invisible to a reader who does not hover and unreachable on touch, which is a large share of this
  audience at a competition. The caption is short so it costs one line of muted label text; the full
  sentence rides in its title attribute for anyone who wants it. **Reversibility: reversible.**
</planner_decisions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a published array's index → a rendered dot's meaning | positional data has no self-describing key on the client either; a length mismatch mislabels which bonus each mark represents |
| absent published data → a rendered mark | the difference between "we do not know" and "it will not happen" is the entire reason `BonusRpState` has three members rather than two |
| a tier colour → a reader's inference about rank | a colour is read as a rank against whatever pool the reader assumes, and the reader's default assumption is the field as of that event |
