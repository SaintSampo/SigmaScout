<objective>
Produce the one walk-forward run every re-issued figure in this phase traces to: 2022-2026, five
algorithms, scored against the event-scoped OPR baseline.

Purpose: SC-2 requires that every OPR figure in `docs/models/` and `PROJECT.md` reflect a real
re-run rather than the retired one. D-11 fixes the field at exactly the five algorithms behind the
current `docs/models/sigma1-tuning-results.md` tables — `opr, epa, sigma1, sigma1-defaults,
sigma1-adapt` — so every table can be re-issued like-for-like rather than differing in both
baseline and field.

Output: `reports/event-scoped-v1/` (gitignored) plus a committed figures fingerprint that survives
it, so plans 03.2-04 through 03.2-06 never depend on a gitignored directory still being present.

**Cost, stated up front so it is sequenced and not discovered.** 03.2-RESEARCH.md measured the prior
five-algorithm five-season run at 6h03m, of which season-pooled OPR contributed roughly 2.5h at
~131ms per update across ~3,700 teams. The rewritten module solves ~39x39 per event in microseconds,
so this run should be dominated by EPA and Sigma1's existing ~3.5h. That is an arithmetic inference
from two real prior measurements, not a measurement of the new code — which is exactly why Task 1
measures one season first and Task 2 does not start until that number exists.
</objective>
