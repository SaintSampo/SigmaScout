<objective>
Capture the season-pooled ridge OPR baseline as committed, reproducible history BEFORE Phase 3.2's
rewrite deletes it (D-13).

Purpose: `docs/models/` will shortly claim "the baseline moved, and here is what it moved from."
Once plan 03.2-02 lands, the season-pooled code no longer exists and its numbers can never be
regenerated from working-tree code.

**A finding that changes this plan's shape, discovered during planning.** D-13's rejected
alternatives assumed "the underlying `reports/tuned-v3/artifact.json` is gitignored and likely
already gone." It is not gone. `reports/tuned-v3/` is fully intact at planning time: `artifact.json`
(schemaVersion 3, `provenance.runTimestamp` `2026-08-17T01:11:06.668Z`, all five algorithms, 75
slices) plus all five `predictions-{season}.jsonl` sidecars (~587 MB total). Its OPR combined slices
read 2022: 0.15234959626676314 / 0.77433909058865, 2023: 0.17061102361607577 / 0.7501576491360827,
2024: 0.1687196006409546 / 0.7501366203169592, 2025: 0.1674797596975863 / 0.7617621652749784, 2026:
0.1773371256148654 / 0.7825409197194076 — which round to exactly the figures published in
`docs/models/sigma1-tuning-results.md`.

That directory is one `rm -rf reports/` away from being gone forever, and it is the *provenance* of
every published retired figure. So this plan captures it FIRST, in minutes, and then still performs
D-13's mandated final full run — because D-13 says the retired code gets a final run, and because
comparing the two digests is a free and genuinely informative control: agreement proves the
season-pooled code at HEAD still reproduces every published number, and disagreement is a real fact
about the record rather than something to reconcile away.

Output: a reusable `packages/harness/baselineFingerprint.ts` generator, its unit test, and two
committed fingerprints of the retired baseline over all five seasons.

**Documented deviation from 03.2-RESEARCH.md / 03.2-PATTERNS.md:** those artifacts recommend a
script named `retireOprBaseline.ts` writing to `data/retired-baselines/`. Both name the placement
constraint as the load-bearing part ("a directory `digest.test.ts` never scans") and both say "or
equivalent" for the script name. This plan uses `packages/harness/baselineFingerprint.ts` writing to
`data/baselines/` instead, because plan 03.2-03 needs the identical generator and schema for the NEW
event-scoped baseline, and SC-3's "both baselines side by side" reads better from one directory with
one schema than from two near-duplicate directories. The hard constraint (never inside
`data/algorithm-versions/`) is preserved and directly tested in Task 3.
</objective>

Create `packages/harness/baselineFingerprint.ts`: a standalone generator that turns one completed harness run directory into a small committed JSON fingerprint. It reads only harness output — it never re-runs a replay itself.

CLI flags (via `node:util` `parseArgs`, matching identifiability.ts's option-block style): `--run-dir` (required), `--algorithm` (required, comma-separated ids), `--seasons` (required, accepting either `2022` or the `2022-2026` range form — mirror the range parse `cli.ts`'s `parseSeasonsRange` performs, importing it if it is exported and duplicating the parse locally if it is not), `--label` (required), `--out` (required, output file path), and `--source-note` (required, free text recording where `--run-dir` came from and how it was produced).

Export a Zod schema `BaselineFingerprintSchema` and its inferred type `BaselineFingerprint`. Define it fresh in this file. It must NOT reuse or extend `PromotedVersionSchema` from promote.ts — that schema requires a non-optional Sigma1-shaped `params` field which OPR has no equivalent of. Shape:
`{ label: string, generatedAt: ISO string, sourceNote: string, runDir: string, runTimestamp: string, corpusIdentity: string, artifactSchemaVersion: number, seasons: number[], algorithms: [{ id, version, perSeason: [{ season, brierScore, winnerAccuracy, scoredCount, predictionStreamSha256 }], predictionStreamSha256 }] }`.

`runTimestamp` and `corpusIdentity` are copied from the artifact's `provenance` object; `artifactSchemaVersion` from its top-level `schemaVersion`. Per-season `brierScore` / `winnerAccuracy` / `scoredCount` are read by selecting the single slice matching `algorithmId === id && season === s && compLevelView === "combined"`. Throw a named error if that slice is absent or ambiguous rather than defaulting to null.

`predictionStreamSha256` is computed by importing `computePredictionStreamDigest` from `./promote.js` and feeding it records reconstructed from `<run-dir>/predictions-<season>.jsonl`, filtered to `algorithmId === id`, in file order — which 03.2-RESEARCH.md verified is the exact chronological replay order. Map each sidecar line into the `{ match: { matchKey }, prediction: { pRedWin, redScore, blueScore } }` shape that function destructures, sourcing `redScore` from `predictedRedScore` and `blueScore` from `predictedBlueScore`. The per-algorithm `predictionStreamSha256` is the digest over every requested season's records concatenated in ascending season order. The sidecars are large (75-157 MB each) — stream them line by line with `readline` over a `createReadStream` rather than reading whole files into memory.

Export `buildBaselineFingerprint(options): BaselineFingerprint` as the pure, testable core (taking already-parsed artifact JSON and already-computed per-season digest inputs) and keep `main()` as the thin I/O shell around it. Write the output with exactly ONE terminal `writeFileSync` after every season has been aggregated, preceded by `mkdirSync(dirname(outPath), { recursive: true })` — an interrupted generation must leave no partial file. Parse the assembled object through `BaselineFingerprintSchema.parse()` before writing so a malformed fingerprint fails at generation time, not at read time.

Add the `pathToFileURL` entry-point guard so importing this module from a test never triggers file I/O. Add `"fingerprint": "tsx packages/harness/baselineFingerprint.ts"` to package.json's `scripts`.

Then prove the whole path end-to-end over all five seasons against the surviving published run — no harness run needed, this is pure post-hoc reading:
