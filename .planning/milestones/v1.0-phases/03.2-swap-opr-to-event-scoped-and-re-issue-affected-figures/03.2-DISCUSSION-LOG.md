## Baseline fidelity (ridge and early-event behavior)

**Briefing given:** ridge shrinkage is roughly `lambda/(observations + lambda)`. Season pooling gave a
team ~30-40 observations (λ=3 → ~7-9% bias); event scope with quals only gives ~12 (λ=3 → ~20%).
So "freeze λ" would hold the constant fixed while roughly tripling its effect.

### Q1: What happens to the ridge term at event scale?

| Option | Description | Selected |
|--------|-------------|----------|
| Drop ridge, min-norm pseudo-inverse | What TBA does; SVD already imported; removes a tuned-by-us constant from the baseline | ✓ |
| Re-pick λ on tune seasons only | Fairly calibrated, but still our constant, and in tension with 03 D-04's freeze | |
| Freeze λ=3 | Smallest change, cleanest attribution; ships a weaker opponent than event OPR has to be | |

**User's choice:** Drop ridge, min-norm pseudo-inverse
**Notes:** Knock-on flagged immediately after: this removes `OPR_RIDGE_LAMBDA` and the
Sherman-Morrison `denom` guard, and invalidates ridge-describing prose in both `opr.ts`'s header and
`sigma1-identifiability.md` — all added to the re-issue list.
