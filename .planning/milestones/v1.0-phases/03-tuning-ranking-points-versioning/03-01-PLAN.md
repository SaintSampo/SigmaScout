tuning→promotion→reproduction spine end to end on one knob before expanding it.

layer this phase will touch — `Sigma1Params` data → `makeSigma1` → the existing leak-proof

remaining task in this phase is expansion along it.

rather than a hardcoded literal. Both are blocked until Sigma1's constants stop being module

parameter can move without dragging EPA's predictions with it.

carry module; `tune.ts`; `promote.ts`; `digest.test.ts`; a committed
`data/algorithm-versions/` directory.
