1. `parsed = ruleModule.parse(rawJson, side, eventType)` — the full rule, with every gating signal visible.

- `understatedRate` — the fraction of alliance-matches where `parsed.bonusFlags[b]` is `true` but `predicted.bonusFlags[b]` is `false`
