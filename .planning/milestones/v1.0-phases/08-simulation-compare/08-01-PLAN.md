## Decisions this plan makes (Claude's Discretion, recorded not assumed)

1. **All five years are committed as fixtures, not just 2026.**
   The outline's assumption 3 named `compare-2026.json` as the parity anchor and left additional
   years as an executor call sized against fixture bytes. Resolved here, at ~14 KB each and ~70 KB
   total: SC-3 is *"every algorithm for every year 2022-2026"* and SC-4 is *"the numbers rendered on
   the Compare page are identical to the versioned artifact"*. A one-year fixture proves the claim
   for one fifth of the rendered numbers and leaves four fifths outside it — exactly the gap EVAL-05
   exists to close. And the page genuinely issues five independent fetches, so a one-year fixture
   forces the test to fabricate four responses anyway: fabricating four is strictly more code and
   strictly less proof than committing four more real files.
   — <reversibility rating="reversible">Fixtures are additive test data; deleting four is a one-line change to the test's mock dispatch.</reversibility>

2. **`ErrorState`'s `year` prop becomes optional rather than the Compare page inventing its own error view.**
   The canonical component hard-codes `Couldn't load {resource} for {year}.`, and Compare is this
   site's first page whose data is not scoped to a single year — there is no honest year to
   substitute across five simultaneous fetches. The Copywriting Contract's exact string for this
   page is `Couldn't load comparison data.`, so the component gains an optional `year` and omits the
   `for {year}` clause when it is absent. All four existing call sites pass a year and render
   byte-identically. 08-12 completes the page's non-populated states across the sections it adds;
   this change is what lets it do so through the canonical component rather than a second one.
   — <reversibility rating="reversible">An optional prop with a branch; every existing caller is unaffected.</reversibility>

3. **The route declares no `validateSearch` of its own.**
   `__root.tsx` already validates `year`/`algorithm` through `RootSearchSchema` at the router
   boundary, and UI-SPEC's Global-dropdown exception is explicit that Compare filters by neither.
   Adding a Compare-specific search schema would create a second, driftable declaration of params
   this page deliberately ignores. The compLevel switcher (08-06) and the calibration year `Select`
   (08-10) are local component state per the outline's assumption 9, so nothing on this page needs
   a search param.
   — <reversibility rating="reversible">Promoting the switcher to a typed search param later is a contained change to `compare.tsx` and `searchParams.ts`, exactly as the outline records.</reversibility>

4. **The header is a two-row grouped header, reconciling UI-SPEC's copy with sketch 007's validated structure.**
   UI-SPEC's shape line reads `Year | OPR Winner Accuracy | OPR Brier | …` while its Copywriting
   Contract fixes the literal header strings as `Winner Accuracy` and `Brier Score (lower is
   better)`, and sketch 007's winning variant A uses a `rowspan=2` row-label header plus `colspan=2`
   algorithm-group headers over a metric sub-header pair. Read together these are one table: the
   shape line describes column *content*, the Copywriting Contract fixes the header *strings*, and
   the sketch fixes the *structure*. This plan ships the sketch's structure carrying the contract's
   strings, so both bind.
   — <reversibility rating="reversible">Header markup, no data contract behind it.</reversibility>

5. **`markArtifactParsed()` is called on each of the five parses, unchanged from every other fetcher.**
   `performance.measure` resolves a repeated mark name to its most recent entry, so parse-to-paint
   on this page brackets the LAST of the five parses — which is the correct reading for a page whose
   content needs all five. Keeping the call identical to `events.ts`/`event.ts` matters more than
   optimising a mark this page's own gate does not read.
   — <reversibility rating="reversible">One call site.</reversibility>
