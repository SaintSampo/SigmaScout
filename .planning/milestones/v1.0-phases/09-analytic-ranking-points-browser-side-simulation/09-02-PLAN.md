<objective>
Turn ten hand-written blocks of comparison code into ten arrays of declared data, behind an unchanged
public function.

Today each of `packages/core/rankingPoints/2016.ts` … `2026.ts` implements `predictThresholds` as a short
block of bespoke comparisons — `hubTotalCount >= ENERGIZED_THRESHOLD[tier]`, `levels.every(v => v >= …)`,
`quintetAchieved ? A : B`, a hardcoded `false`. Those blocks are correct and measured, but they are
opaque to anything that wants to reason ABOUT them rather than run them. 09-04 needs to group bonuses by
shared threshold variable and enumerate joint outcomes from marginal CDFs; it cannot do that against
comparison code, only against declarations.

This plan adds to `packages/core/rankingPoints/constants.ts` a `BonusPredicate` discriminated union
covering exactly the seven mechanism classes verified across all 21 bonuses in all ten registered seasons
— `singleThreshold`, `linearCombination`, `conjunctionDistinct`, `nestedSameVariable`,
`countOfIndicators`, `dataDependentMixture`, `constant` — plus a `MarginalFamily` union and a
`marginalFamily` field on `RpThresholdVariable` beside the existing `unit` (D-02). Each season module then
declares `BONUS_PREDICATES`, derives `BONUS_NAMES` from it, and reimplements `predictThresholds` as a
one-line delegation to a single shared `evaluateBonusPredicates`.

The bar is byte-for-byte behavioral identity, and the plan is built around proving it: an oracle captured
from the pre-rewrite code before any module is touched, and the existing corpus-backed
`rpConservativeBranch.ts` measurement re-run against the rewritten code and diffed. D-07 removed the
Monte Carlo equivalence check that would otherwise have been this phase's strongest correctness evidence,
and named unit tests as the required mitigation — this plan's oracle is the first instalment of that debt
being paid, one layer below the hand-computed per-mechanism cases 09-04 owes.

Purpose: this is the contract 09-03, 09-04 and 09-05 are all written against. 09-03 dispatches on the
`MarginalFamily` union and the `marginalFamily` field. 09-04 groups bonuses by `BonusPredicate` kind, and
specifically needs `nestedSameVariable` distinguishable from `conjunctionDistinct` at the type level,
because treating 2026's two thresholds on one variable as independent understates the joint and is the
exact modelling error the contract exists to prevent (D-07). 09-05 flips the family declarations this plan
plants. Nothing downstream can start until the names exist.

Output: one extended leaf module, ten converted season modules, a committed behavior oracle and its
replay test, and extended structural assertions in `rules.test.ts`. **Nothing ships, nothing publishes,
no number changes.** Every predicted bonus probability in the repository is identical before and after
this plan, by construction and by measurement.
</objective>
