## Decisions this plan makes (Claude's Discretion, recorded not assumed)

1. **The event page's season comes from the event key and the artifact, never from `?year=`.**
   `artifactKey`'s `event` branch carries **no year segment** (verified: `v1/event/{eventKey}/{algorithmId}@{version}.json`), and `EventArtifactSchema.season` is a required published field. So `metricKeysFor` is called with `artifact.season`, and the pre-fetch skeleton's column count with `seasonFromEventKey(eventKey)`. `?year=` survives on `EventSearchSchema` only because `RootSearchSchema` owns it and the globally-mounted ribbon reads it. A hand-edited `/event/2024casf?year=2026` therefore renders 2024's real column set rather than a mismatched one.
   — <reversibility rating="reversible">A season source is a one-call-site change with no published contract behind it.</reversibility>

2. **`EVENT_TABS` declares all five ids; the ROUTE narrows to the registered subset.**
   The outline's stated mechanism — an unbuilt `?tab=` value resolving through `.catch(DEFAULT)` — does not actually fire, because `.catch()` only runs on a *parse failure* and `insights` is a member of the enum, so `?tab=insights` would parse cleanly and hand Radix a value with no matching trigger or content (an empty panel between waves). Corrected here without changing scope: `EventSearchSchema`'s enum stays over all five ids so the URL contract is stable across the phase and 07-18's default flip is a one-constant edit, and `routes/event.$eventKey.tsx` declares a module-local `REGISTERED_EVENT_TABS` array that each expansion plan appends its own id to in the same edit where it adds its trigger. This keeps every `searchParams.ts` change inside the outline's three plans (07-01 creates, 07-16 renames, 07-18 cuts over).
   — <reversibility rating="reversible">A local narrowing array; deleting it once all five are registered is a one-line change.</reversibility>

3. **`/event/$eventKey` becomes a public, shareable URL on the next push.**
   `.github/workflows/deploy.yml` deploys Cloudflare Pages on every push to `main`, so this path shape is externally linkable from the moment this plan merges. Chosen to mirror `/team/$teamNumber` exactly.
   — <reversibility rating="costly">Changing the path later breaks external links and needs a redirect; flagged only — the outline places this phase's `checkpoint:decision` gates at 07-17 and 07-19, and nothing here is irreversible at its own commit.</reversibility>

4. **A 404 gets its own non-Retry empty state, distinct from a connection failure.**
   Mirrors 06-01's shipped 404-vs-other-error split. Measured live this session: `v1/event/2025isios/sigma1@2.0.0+tuned-2026-08.json` returns 404 today, and will for every offseason event until 07-09 wires `--include-offseason`. Offering "Check your connection and try again" with a Retry button for a key that was never written would be false.
   — <reversibility rating="reversible">Copy and a branch.</reversibility>

5. **Breakdown uses pinned columns WITHOUT a row virtualizer or a viewport-filling scroller.**
   `TeamsTable.tsx` measures a viewport-filling height and virtualizes because it is a whole-page table over thousands of teams. An event roster is 20–60 teams (measured: 43 at `2024casf`, 6 at `2024txcmp`), and a viewport-filling scroller inside a tab panel would fight the page's own vertical scroll. Breakdown reuses `columnPinningFeature` + `columnSizingFeature` inside a single native `overflow-x-auto` region and nothing else from `TeamsTable`'s scroll machinery.
   — <reversibility rating="reversible">Adding virtualization later is additive.</reversibility>
