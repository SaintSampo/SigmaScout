## Decisions Made

- **WR-03's season assert could not be written as the review's own text proposed.** The review's literal fix reads `s.season === artifact.season`, but `CompareArtifact` (`PagePreambleSchema` + `algorithms` + `slices`) carries no top-level `season` field — verified against `packages/harness/pageArtifacts.ts:1262` at plan time. `season` lives on each SLICE, so only the CALLER (who fetched a specific year) can supply it. `pooledAccuracyPodium`'s signature changed from `readonly CompareArtifact[]` to `readonly SeasonedCompareArtifact[]` — a list of `{ season, artifact }` pairs — instead.
- **IN-01's `metricsOverride !== undefined` was not a trustworthy signal before this task.** `team.$teamNumber.tsx` used to compute `headerMetrics` as `officialSnapshotMetrics(...) ?? data.seasonStats.metrics` — so a team with no official snapshot still received a DEFINED (but season-final) override. Labelling that "As of last official match" would have shipped a new false claim while fixing a missing one. The route's fallback was removed first (behaviour-preserving for the rendered numbers, since `SeasonHeader.tsx:64` already resolves the identical fallback one layer down); only after that change does `metricsOverride !== undefined` mean "a genuine snapshot resolved."
- **`08-REVIEW`'s WR-02 fix was retired deliberately, not lost.** The deleted `CalibrationChartCell` type carried a `point` field added by a prior review's WR-02 fix (avoiding a float-keyed lookup that could misattribute a hover/click). That fix protected code — the reliability-diagram chart — that this task's WR-07 confirms has no consumer anywhere; the fix and the code it protected are retired together, on purpose.
- **WR-07's `CalibrationSection.tsx` empty-state copy is a deliberate, user-visible change.** The card's `card.headline === null` branch used to render an inlined jargon string ("No usable bins in this view."); it now renders `calibrationSeries.ts`'s own `NO_USABLE_BINS_SENTENCE` ("Not enough matches to show a calibration result for this selection."). Verified at plan time that no test asserted the old string, so nothing broke — but the visible text a reader sees in that state is different, by design (plain-language-first, matching `Skill("sketch-findings-sigmascout")`'s stated direction).
- **IN-01's exact caption wording was authored fresh, not copied from the review.** `sketch-findings-sigmascout`'s `uncertainty-display.md` covers as-of disclosure in principle (draw the whole predictive-variance quantity, never a partial one) but names no specific caption text for this surface. The review's suggested "As of last official match" wording was kept for the snapshot case (no conflict found), paired with a plain "Season-final (includes offseason/preseason play)" caption for the fallback case and a third caption on the record row naming its own, always-season-final basis — no deviation from the skill was needed because none of its rules spoke against this wording.
