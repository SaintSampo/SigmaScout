# Quick task 260908-3k5: GBR — Gradient-Boosted Rating, a standalone research package Summary

**One-liner:** Hand-rolled histogram gradient-boosted trees over 25 season-normalized walk-forward features, rolling-origin validated on 2016-2025 with a sealed, unbroken 2026 holdout — a structurally independent FRC match predictor sitting alongside OPR/EPA/VPR/BPR.

## What was built

Three commits, exactly as planned:

1. **`2fbe24e5`** — `cli.ts` (year vocabulary, THE SEAL's declaration), `data.ts` (corpus loader with the seal's teeth: `loadSeason` throws for 2026 unless `{ breakSeal: true }`), `features.ts` (the season-transfer core: Welford-normalized per-team state, the 25 enumerated match features per P-9, antisymmetry machinery), plus `features.test.ts` and `seal.test.ts`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The bin/raw agreement test's first design could not have caught the bug it existed to catch**
- **Found during:** Task 2, while performing the required red-then-green proof for the bin/raw threshold off-by-one control.
- **Issue:** The initial `gbdt.test.ts` bin/raw agreement test re-derived the comparison bin index from the serialized raw `threshold` via `binOf(thresholds, threshold)`, then compared that against `predictForest`'s own raw-threshold walk. Both sides derived their routing decision from the *same* stored value, so injecting a genuine off-by-one (storing `t_{b+1}` instead of `t_b`) left the test green — internally self-consistent regardless of the bug.
- **Fix:** Added a diagnostic-only seam to `gbdt.ts` — an exported `TreeNode` type (carrying the internal `splitBin` used to actually route rows during training, never serialized) and an optional `debugTrees` parameter on `fitForest`. The test now compares the actual training-time bin-routing decision against `predictForest`'s raw-threshold walk — a genuine cross-check. Red-then-green re-proven against the corrected test.
- **Files modified:** `packages/gbr/gbdt.ts`, `packages/gbr/gbdt.test.ts`
- **Commit:** `9c692838`

### Judgment calls within plan scope

- **`evaluate.ts`'s default GBDT hyperparameters** (`maxDepth=5, learningRate=0.1, minChildWeight=5, lambda=1, subsample=0.8, colsampleByTree=0.8, seed=42`) chosen as mid-range defaults, verified to land the 2022-origin smoke inside the required accuracy band (0.7668).
- **`OriginResult.marginMae`/`totalMae`**: added (present only under `--heads all`) so the margin/total heads are exercised end-to-end, not fit-and-discarded.
- **`holdout.ts`'s offseason-only slice**: computed accuracy/Brier restricted to `eventType 99/100` matches within 2026 — the 2026 offseason is the proxy for 2027. Not exercised since the holdout was never run.
