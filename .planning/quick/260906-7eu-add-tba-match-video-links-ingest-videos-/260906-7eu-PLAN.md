`parseMatchVideoKey(raw)`:
- A plain 11-character YouTube id returns that id with no start time.
- An id with a trailing seconds-style timestamp query suffix returns the bare id plus
  the start time in whole seconds.
- An id with a trailing minute-and-second-style timestamp suffix returns the bare id

- Produces a privacy-mode embed origin, the parsed id as the final path segment, and

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TBA API -> ingest | Third-party JSON; the `videos[].key` value is attacker-influencable in principle and is never trusted as-is |
| published artifact -> browser | The stored key reaches the client verbatim and is interpolated into an iframe `src` |
| SigmaScout page -> youtube-nocookie.com | A third-party origin is embedded inside the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-7eu-01 | Tampering | `parseMatchVideoKey` -> iframe `src` | high | mitigate | A stored key is never interpolated into a URL unvalidated. Task 2's parser allowlists the YouTube id character set and a length bound and returns undefined otherwise, so a `javascript:`, `data:` or foreign-origin payload renders no control at all rather than a live frame |
| T-7eu-02 | Elevation of Privilege | embedded iframe | medium | mitigate | The embed carries an explicit `allow` list rather than inheriting the page's full permission set, and a `strict-origin-when-cross-origin` referrer policy |
| T-7eu-03 | Information Disclosure | third-party embed | low | mitigate | `youtube-nocookie.com` rather than `youtube.com`, and the frame is not mounted at all until the reader chooses to open it, so a page view sets nothing |
| T-7eu-04 | Denial of Service | event page with ~80 rows | medium | mitigate | Structural laziness: Radix mounts `DialogContent` only while open, asserted by a zero-iframe test rather than trusted. 80 eager embeds would be a page-load regression on the venue wifi this audience uses |
| T-7eu-05 | Tampering | corpus migration | high | mitigate | Additive `ALTER TABLE ADD COLUMN` only, copied verbatim from the established `EVENT_LOCATION_COLUMNS` pattern; nothing drops a table, deletes rows, or copies into a replacement table, so the large unrecoverable live corpus is safe |
| T-7eu-SC | Tampering | package installs | high | accept | This plan adds no dependency. Radix, the dialog primitive and Zod are all already installed and already audited |
</threat_model>
