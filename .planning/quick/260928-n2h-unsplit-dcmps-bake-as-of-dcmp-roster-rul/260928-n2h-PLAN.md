## Task 1: the district bake prices an unsplit DCMP (F2)

`classifyBakeCandidate` (scripts/publishDistricts.ts) refuses every `eventType === 2` event as `divisioned-dcmp-parent`. Only a DCMP with divisions should be refused. The corpus marks divisions as `event_type` 5 whose `event_key` starts with the parent's key. In 2026, micmp has 4 and necmp, oncmp and txcmp have 2 each. The other 11 type 2 DCMPs have none: cancmp, cascmp, chcmp, gacmp, incmp, iscmp, mrcmp, nccmp, pncmp, sccmp and wicmp.

- Refuse a type 2 event only when it has at least one division.
- Pass the set of divided parent keys into the classifier as data. The classifier stays pure.
- Keep the reason string `divisioned-dcmp-parent` for the divided case.
- Check the alliance count and field size an unsplit DCMP bake uses (expect 8 alliances), and report them.
- Test: an unsplit type 2 event is a candidate; a divided one is refused.
- Verify with an as-of dry run at 2026-04-04. An unsplit DCMP whose district events are all final should now bake. Use the as-of rule from Task 2 so it is not baked from a season-final roster.

## Task 2: an as-of run does not bake a DCMP before its field is knowable (F1, the DCMP part)

As-of runs read season-final rosters (`event_teams`). A DCMP's roster depends on that district's results. In an `--as-of` run only, a DCMP tier event (type 2 or type 5 division) is refused with a new reason, `dcmp-field-not-final-as-of`, until every regular district event of its district has finished before the instant. At "now" the rule must be a no-op, because TBA lists a DCMP roster only after qualification; prove that with a pinned-clock no-as-of dry run, byte-identical to before.

The general part of F1 (regular event rosters and schedule lengths are season-final) cannot be fixed without roster history. Document it in the publishDistricts.ts header, next to the existing list of what an as-of run still reads season-final.
