## Deviations from Plan

1. **[Bug] Skeleton spacer reserved nothing (fixed, `9f247094`).** The executor put the spacer inside the `h-[280px]` skeleton box, where it overflows instead of adding height, so the landed legend would still have shifted the page 24px. jsdom has no layout, so the unit test passed on DOM presence alone. Fixed by returning a fragment that mirrors the chart (280px box, then spacer as a sibling); tests now pin the sibling relationship on both the skeleton and the chart legend. Measured delta 0 in Chromium.
2. **[Bug, found in the look check] Y tick labels anchored to the band edge (fixed, `9c6c2f82` + `b5babfcc`).** Recharts anchors a fixed domain's ticks at its own minimum. Once a band's lower edge went below zero, every label offset by it: `-18.71, 131.29, 281.29` (2481) and `-74.29, -34.29, 5.71` (4191). `niceYAxis` now rounds both bounds outward to a 1/2/5 x 10^n step and passes the exact ladder, so zero is always a tick and each bound moves by less than one step. Side effect on every algorithm: the odd top label goes away (2481 real data read `0, 150, 300, 418.64`, now `0 ... 500`). All existing G-13, axis-width and zero-baseline tests pass unchanged.
