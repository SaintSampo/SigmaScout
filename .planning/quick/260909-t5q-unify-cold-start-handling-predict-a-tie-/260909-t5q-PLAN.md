<objective>
Unify cold-start handling across OPR, EPA and BPR: when all six robots in a match are making their
corpus-first appearance, every algorithm predicts a tie, the match leaves the scored population
into a new visible exclusion bucket, the Call column shows a neutral glyph, and the comparison
methodology post documents the rule.

Purpose: today each algorithm improvises on this structural edge case. A forced guess with no
information behind it is being scored against an outcome it could not have predicted, and the
three algorithms disagree about which matches those are — so Compare's coverage rows silently
compare different populations. 2016 is the corpus's first season and carries almost all of these.

Output: one shared predicate in `packages/core/`, a cold-start exclusion threaded through the
harness and every schema, report and coverage surface that enumerates exclusion keys, the glyph on
both match tables, methodology copy, and a census of what a future republish would change.

**Decision map** (CONTEXT.md `<decisions>` → the IDs cited throughout this plan):

| ID | Locked decision |
|----|-----------------|
| D-01 | Definition of unseen — corpus-global first appearance; ONE algorithm-independent predicate; per-algorithm state and season-global first appearance both explicitly REJECTED |
| D-02 | Exclusion scope — both winner accuracy AND Brier; a new key on `exclusionCounts`; keyed off the structural flag and never off the probability value, so an ordinary no-call keeps its D-Q3 treatment |
| D-03 | Tie symbol — em dash, in BOTH match tables, with an accessible label distinct from the existing correct/incorrect labels; how an ACTUAL tie renders stays as-is |
| D-04 | Republish deferred — code, tests and docs only; the task MUST report what a republish would change |
</objective>
