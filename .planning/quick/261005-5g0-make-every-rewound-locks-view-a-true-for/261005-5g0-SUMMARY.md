## What changed

At every match fold the six teams' state and the league row are captured. The offline publisher
and the live Worker call one shared reducer. Published per event: an INDEX and a LOG; per season:
a season object (league start row, tails) and a start object (every carried team's pre season
state). SPR only. The browser rebuilds each team's state at the chosen stop and prices from it.

- Both Locks tabs at a rewound stop: every remaining match is priced from the state at the stop;
  draft and playoff ratings come from that same state; an event whose schedule was not known at
  the stop runs over generated schedules (40 x 100, the offline bake's own function, in a second
  Web Worker); no stored per row prediction, `teams[].metrics` or baked sidecar is read.
- Playoffs and Awards stops sit at the event's last played playoff match. A category open now is
  never final at an earlier stop.
- Event page Simulation tab: an SPR rewind prices from the state just before the start match.
  EPA and OPR are unchanged. Unpublished as-of files fall back to today's stored rows.
- Rewind note removed; Methodology states the as-of rule in one sentence. The todo
  `locks-rewind-as-of-forecasts` is closed.
- No D1 change. `STATE_SNAPSHOT_SHAPE_VERSION` stays 18. No SPR version bump (decision C).

## Known limits

- Rosters at a stop are the teams that actually played; TBA keeps no registration history.
- A stop between an event's last qualification match and its real alliance selection reads
  alliance points as final once selection has happened.
- The Simulation tab's cut is the previous row of the same event, so other events' matches in
  the minutes between are not in the league row. Conservative, never later knowledge.
- Live Worker only, healed by a republish: concurrent events fold in tick order, so a league row
  can differ from the replay's; a lost season object write followed by the team's next match at
  another event can leave a stale back pointer.
- `etagDoesNotMatch: "*"` on the season object's first put was not checked against real R2.
- Divisioned DCMP parent playoff table (pooled 2023 to 2026) and the Locked guarantee maxima are
  unchanged.
- `scripts/measureChampCutoff.ts` still measures the retired stored odds rewind path.
