# Quick task 261006-2t0: simulation baselines from qualification rows only

Jacob's decision on quick task 261006-2mg: ship the web half now, the sidecar half with the next
republish. Thirteen events carry playoff-only demo robots in their match-derived `teams[]`, and
every browser roster site reads that list, so the per-match Simulation tab, the rewound Locks
view and the live Locks ledger all rank robots that never played a qualification match and read
an inflated field size.

## Task 1: one roster rule in `simulationInputs.ts`

Add `simulatedTeams(artifact)`: the `teams[]` rows whose team is on at least one qualification
row from `buildQualRows`, or the whole list when the artifact has no qualification row (the
registered roster before the schedule posts, the publisher's own fallback). Use it in
`buildSimulationInputs`, in `asOfRewind.ts` (`finalRankingBaselines` and the mid-event
`teamKeys`), and in `districtLedgerRows.ts` (`finishedQualBaselines`), so `fieldSize` falls out
right at every site.

## Task 2: regression tests

One case per site with a 2026txmca-shaped fixture (a demo row in `teams[]` on no `qm` row):
no baseline for it, the field size equals the qualification roster, and the no-qualification-row
artifact keeps its whole list.
