<objective>
Remove every sticky (frozen-left) column from the event page's tables: Insights, Breakdown, Quals, Playoffs (Elims), Alliances, and the Simulation tab's rank-distribution table. User's words: "on an event page, get rid of sticky columns on all the tables, including insights, breakdown, quals, and playoffs and alliances."

Purpose: the user wants every event table to scroll as one piece horizontally. This follows the 2026-09-13 precedent where the team page's MatchTable dropped its sticky columns (commit ef07aad4).

Output: five components with no horizontal pinning, unit tests that assert "no sticky column" at wide AND narrow widths, and Playwright specs that no longer assert frozen columns hold position.

Column-order decision (Claude's discretion, per the constraints): REMOVE TanStack column pinning entirely (the pinning feature registration, the pinning state, and the per-cell pinned styling), rather than keeping pinning state for ordering. Pinning state is not needed for ordering. Every table's column definition order already puts the formerly-pinned ids first: Insights is rank, teamNumber, nickname, then the rest. Breakdown is teamNumber, nickname, metrics. Alliances is allianceNumber first. RankDistribution is teamNumber, nickname, medianDisplay, distribution. Removing pinning therefore cannot reorder anything. The sizing APIs (column and header `getSize`, `getTotalSize`) belong to `columnSizingFeature` in @tanstack/table-core 9.1.2, so they keep working. `useTable`'s `state` option is optional.
</objective>
