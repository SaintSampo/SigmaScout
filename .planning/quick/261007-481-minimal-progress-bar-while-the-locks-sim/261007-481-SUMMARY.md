# Quick Task 261007-481: Minimal progress bar while the Locks simulation runs Summary

Both Locks tabs now show a 4px rounded bar as the last row of the controls card while the tab waits on its per event simulation. It shows N of M events while the run is in flight, an animated sweep while it waits in any other way, and a static soft bar under reduced motion. It is an accessible progressbar named "Simulation progress". (Jacob, 2026-10-07: "add a minimal progress bar for when the simulation is running")

## What was built

- **`ledgerRunProgress.ts`**: a pure derivation with no React at runtime (the hook is imported as a type only). Neither artifacts loading nor run pending gives `undefined`. A running state with `totalEvents > 0` gives determinate, with `completed` clamped into 0..total. Anything else gives indeterminate.
- **Copy**: `DISTRICT_LEDGER_RUN_PROGRESS_LABEL = "Simulation progress"` and `districtLedgerRunProgressText(completed, total)`, which uses the singular noun for one event. No dash characters.
- **CSS (theme.css, inside the Locks milestone picker block)**:
  - `@keyframes locks-progress-sweep`
  - a `:root` block holding `--locks-progress-track: var(--color-border)` and `--locks-progress-fill: var(--color-accent)`
  - `.locks-progress`: 4px high, rounded, overflow hidden
  - `.locks-progress-fill`: a 200ms width transition
  - the indeterminate rule: 30% width plus the sweep
  - the reduced motion block now also lists `.locks-progress *` and turns the indeterminate fill into a static full width `var(--locks-picker-accent-soft)` bar
- **`LedgerParts.tsx`**:
  - New `LedgerRunProgressBar`, with role progressbar, aria-label and `data-progress`.
  - Determinate mode adds aria min, max, now and valuetext, plus an inline `width` only.
  - Indeterminate mode adds `aria-busy="true"` and no value attributes.
  - All class names are plain string literals.
  - `ControlsCard` gains an optional `progress` prop and renders the bar as its last child. When `progress` is undefined no space is reserved.
- **Wiring**: `DistrictLedger.tsx` and `ChampLocksLedger.tsx` each make the same one-line `ledgerRunProgress({ artifactsLoading: artifacts.isLoading, runPending: data.runPending, runState: data.runState })` call and pass `progress={runProgress}`.
