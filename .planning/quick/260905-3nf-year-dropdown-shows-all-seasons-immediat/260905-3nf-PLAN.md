# Quick Task 260905-3nf: Year dropdown shows all seasons immediately

## Problem

After picking 2019 in the ribbon's year dropdown, reopening it requires scrolling up to
reach 2026. `ui/select.tsx`'s `SelectContent` defaults to Radix `position="item-aligned"`,
which reopens the list with the selected item aligned over the trigger; the ribbon sits at
the top of the viewport, so everything above the selected item is clipped behind a
scroll-up button. The user asked for the full list to be visible immediately.

## Tasks

1. **Flip `SelectContent`'s default `position` to `"popper"`** in
   `apps/web/src/components/ui/select.tsx` (the current upstream shadcn default). Popper
   mode renders the whole list below the trigger. This fixes all six dropdowns (year,
   algorithm, two event filters, calibration season) consistently, not just the year one.
   - Watch: the popper-mode viewport class references
     `--radix-select-trigger-height`; verify empirically that the open list is not
     height-clamped to the trigger.
2. **Verify visually** against the running app (dev server + Playwright screenshot):
   open the year dropdown with 2019 selected; all seasons 2026..2019 must be visible
   with no scroll. Run the ribbon unit tests.

## Constraints

- apps/web only. Another agent is mid retune/republish: no pipeline, publish, or R2 code;
  stage commits by explicit path only.

## Done

- Year dropdown (and every other Select) opens showing the full option list below the
  trigger regardless of which option is selected; ribbon/select tests green.
