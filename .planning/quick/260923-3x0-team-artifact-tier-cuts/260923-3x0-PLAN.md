# Publish `tierCuts` on the team-season artifact

## Task

Since quick task 260923-3w7 the robot page reads only its own team-season artifact, so a
live-folded metric-history row (one the Worker appended during an event: a metric VALUE with
no `percentile`) renders UNTIERED until that event's next republish. The rarity-tier cut
points lived only on the EVENT artifact, which the robot page no longer fetches.

Fix: publish the same per-(algorithm, season) `tierCuts` block on the team-season artifact.
It is already built once per (algorithm, season) by `buildTierCutsFromPools` for the event
artifacts, so this is a key and a carry-forward, not a new computation.

Published numbers do not change. No algorithm version bump. `PAGE_ARTIFACT_SCHEMA_VERSION`
is not bumped (additive optional key, this file's own precedent).
