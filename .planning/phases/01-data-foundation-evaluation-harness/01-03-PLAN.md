<objective>
Expand the tracer's single-event ingest into the full 2022–2026 corpus, and make every TBA data quirk an
explicit, queryable flag.

Purpose: DATA-02's success criterion is not "handle the quirks" — it is that surrogates, replays, missing
score breakdowns, and offseason events each appear as explicit flags, with none silently ingested and
none silently dropped. The hardest of these is replays: RESEARCH.md Pitfall 1 establishes that TBA's
public API exposes no replay field at all, so a plain upsert-by-match-key keeps the right final score
while destroying the fact that a replay happened. D-08 requires that fact. It has to be synthesized by
diffing against what was already stored, which makes replay detection load-bearing rather than
incidental.

Output: A populated corpus for 2022–2026 with per-quirk flags, a conditional-request client whose repeat
runs cost 304s, and one test per quirk.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `packages/ingest/schemas.ts` at the fetch boundary | medium | mitigate | Every response is Zod-parsed before normalization; a shape change in TBA's payload throws and halts the run rather than writing coerced defaults across five seasons of corpus |
| T-01-04 | Denial of Service | Outbound request volume in `tbaClient.ts` | medium | mitigate | Throttle enforced inside the client so no call site bypasses it; conditional requests make repeat runs 304-only; per-run request and 304 counts persisted to `ingest_runs` so volume is measured, not assumed; the client exposes only the eight capabilities COVERAGE.md marks INTEGRATE |

| T-01-08 | Tampering | Concurrent writers corrupting the corpus | low | mitigate | WAL plus a single-writer lock; a second concurrent ingestion fails fast with a readable message instead of interleaving writes |
