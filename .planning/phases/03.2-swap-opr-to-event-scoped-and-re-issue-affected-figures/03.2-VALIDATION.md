## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.1.x (project-wide) |
| **Config file** | Repo-root Vitest config (existing) |
| **Quick run command** | `pnpm vitest run packages/core/algorithms/opr.test.ts` |
| **Full suite command** | `pnpm test` (plus `pnpm typecheck`, per `.github/workflows/test.yml`) |
| **Estimated runtime** | Quick ~5s (synthetic fixtures, no corpus); full suite minutes |

**Out-of-band cost that no test substitutes for:** this phase requires two real
walk-forward harness runs against the ~351MB corpus, together roughly **5–7 hours**
of wall-clock time (retired season-pooled run ~80 min; the five-algorithm
event-scoped run, with old OPR's ~2.5h replaced by a microsecond-scale per-event
solve). Plan sequencing must treat these as long-running steps, not test steps.

  detector for the D-13 fingerprint-placement pitfall
- **Before `/gsd-verify-work`:** full suite green AND both required harness runs
  complete with their artifacts/fingerprints committed
- **Max feedback latency:** ~5 seconds for the quick loop
