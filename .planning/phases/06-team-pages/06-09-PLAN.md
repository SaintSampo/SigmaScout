<objective>
Make first paint independent of the JavaScript bundle, and give the phase's new surfaces the depth
the developer asked for after Phase 5.

Purpose: this app is a pure client-rendered single-page app, so nothing paints at all until roughly
600 KB of JavaScript downloads, parses and executes. The largest-contentful-paint element is the
ribbon's wordmark, which cannot render until React mounts. On the congested-venue profile — the
representative case for a competition weekend in an arena with thousands of people sharing wifi —
that measures around 4.06 seconds against a locked 2.5-second threshold. This phase adds a chart
library on top, so fixing the budget belongs in the phase that would otherwise worsen it.

The second half is the developer's own Phase 5 sign-off note: the UI is too minimal and rough around
the edges, and there should be a little bit of colour. The rough edges were real defects and were
fixed. "Too minimal" was not a defect — it is the specification working as written — so this is a
disagreement about degree, and only the half of it that stays inside the current system is in scope.

Output: a static shell that paints before JavaScript runs, a dated before/after measurement, and a
polish pass that adds depth without touching the palette.
</objective>
