<objective>
Prove the whole Phase 5 read path end to end, on real infrastructure, with real data, before anything
else is built: a browser at `https://www.sigmascout.org` fetches
`v1/teams/2024/sigma1@2.0.0+tuned-2026-08.json` from `https://sigmascout.org`, validates it against the
same Zod schema the pipeline published it with, and renders real team rows.

Purpose: every remaining plan in this phase assumes that path works. Three things can make it not work,
and all three are cheaper to discover now than after six plans of components exist on top of them:
R2 sends no CORS headers by default (D-18), `packages/harness/pageArtifacts.ts` currently drags
`node:fs` into any bundle that imports it (via `metricHistory.ts`), and no Cloudflare Pages project
exists yet. This plan resolves all three and leaves a live page behind as the proof.

Output: a provisioned Pages project on the site's real domain, a scoped R2 CORS policy, browser-safe
schema leaf modules in `packages/harness`, and a scaffolded `apps/web` whose Teams route renders real
published data on a deployed origin.
</objective>
