<objective>
Deliver the Events page: every event for the selected year, sortable, filterable by week, country,
state or province, and district — inline on desktop, in a sheet on a phone.

Purpose: EVNT-01 is the phase's second page and the one whose data only became possible in plan 05-02.
The interesting work is not the list; it is the four filters' honesty. Every one of those fields is
nullable, and the difference between "this event has no district" and "this event's district is
Unknown" is exactly the kind of quiet coercion that makes a filter lie. This plan writes that rule down
once, in a pure function, with tests.

Output: the events fetcher, a tested filter model, the list with its four states, and the two filter
layouts — all bound to the URL so a filtered view is shareable.
</objective>

    - `filterOptions` excludes null entirely: a set of events where half have no district yields a district option list containing only the real districts, with no null, no empty string and no Unknown entry.

    - `applyEventFilters` with two dimensions set returns the intersection, not the union.
    - `applyEventFilters` with a value that matches nothing returns an empty array rather than falling back to everything.
    - `applyEventFilters` never matches an event on a dimension where the event's value is null, for any filter value.
