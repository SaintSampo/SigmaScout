## Verdict

The site works. All tests pass (5,277 across 235 files), all three typecheck targets are clean, and
origin serves the code at HEAD. Every browsing flow is wired end to end. Two of the 38 v1
requirements no longer hold at HEAD, though, and the FAIL gate forces `gaps_found`. (ALGO-05 was also listed here and was cleared the same day by 260914-ndu; see below.)

| Req | What it promises | Why it no longer holds |
|-----|------------------|------------------------|
| **DATA-04** | New results on the site within ~1–3 min | The live path is gated closed. Behind the gate it reprices from partial state, writes rows missing fields, stalls on a 3+ match backlog, and open pages never poll |
| **DATA-05** | Fits the free tier's 10 ms CPU | A realistic tick measures 13 ms p50 / 28 ms p90; the chosen fix is not built |

The remaining gaps come in one group:

- **DATA-04 and DATA-05 are the live Worker.** STATE.md already names the next container: a
  pre-season phase for the CPU work. This audit adds four defects to that phase's scope, found
  behind the same gate: partial-state repricing, row-shape parity, backlog liveness, and no web
  polling. Nobody sees any of them today, because no live window may open.
- **ALGO-05 was cleared 2026-09-14 (quick task 260914-ndu).** Jacob authorized spending 2023-2026,
  and a pre-registered on/off test ran there. Adaptation helps against the best non-adaptive model:
  Brier +0.00126 [0.00061, 0.00188], accuracy +0.077pp [-0.132, +0.289]. The fast-form component helps
  clearly; the scale's recency weighting hurts. The requirement text now names SPR. See REQUIREMENTS.md.

**ALGO-06 was re-issued 2026-09-14 (Jacob).** Only the current version of each algorithm stays
published, and a version identifies one fixed output, so any change to published numbers bumps the
version. That is a deliberate scope reduction, recorded in REQUIREMENTS.md. `spr@4.0.0` maps to one
output today (`3ba2b580`); its three earlier in-place republishes predate the rule.
